Trading Logic

Connects to Deriv using a Personal Access Token and trades ACCU (accumulator) contracts on Volatility indices.

1 · Connection & Subscription

  • The App ID is hardcoded into this build and hidden from the UI.
  • You only supply your own PAT token in the AUTH panel.
  • Flow: accounts list → real account → OTP → authenticated WebSocket.
  • Subscribes to real-time ticks and balance updates.
  • Ticks are filtered by symbol and subscription ID, so only the currently selected index drives the price display.
  • If Deriv reports that we're already subscribed to a symbol, that response is treated as benign — ticks are already flowing.

2 · Auto-Trade Cycle

  • Auto-trade fires a trade every N ticks (user-set) and continues running until you toggle it OFF.
  • After each trade settles (sold, expired, won, or lost), the cycle resets and the tick counter starts fresh for the next trade.
  • The log shows the live market price on every tick.

3 · Balance Guard

  • Balance must be at least $1.00 USD (MIN_BALANCE_USD).
  • Stake must not exceed the current balance.
  • If either fails, an alert pop-up appears and the tick counter does not start.

4 · Contract Stats

  • Wins, losses and total P/L update after every settled contract.
  • Settlement is detected when Deriv marks the contract as is_sold: 1, is_expired: 1, or reports a terminal status (sold, won, lost, expired).

5 · Markup Statistics (Admin-Protected)

  • The Markup tab requires an admin password before showing commission statistics.
  • Once unlocked, the session stays unlocked until you press 🔒 LOCK or reload the page.
  • No trading login required — the tab uses the hardcoded App ID and hardcoded markup PAT.
  • Date range = 1st of current month → today, computed in local time.
